# Portafolio Angular

Portafolio personal de Santiago Ospina Gonzalez, desarrollador full-stack
de Guadalajara de Buga, Colombia.

## Desarrollo local

```bash
npm install
npm start
```

La aplicación se abrirá en `http://localhost:4200/`.

## Construcción

```bash
npm run build
```

La configuración de GitHub Pages y los cinco proyectos independientes se
agregarán en una etapa posterior.
